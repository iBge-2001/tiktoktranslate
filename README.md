# TikTok 翻译助手 · 更新发布渠道

本仓库**只用于发布软件更新包**，不包含任何源码。

## 买家使用

不需要来这个页面手动下载。软件内双击「一键更新.bat」即可自动检查并安装最新版本。

固定地址：
- 版本信息: `https://github.com/iBge-2001/tiktoktranslate/releases/latest/download/version.json`
- 更新包:   `https://github.com/iBge-2001/tiktoktranslate/releases/latest/download/update.zip`

## 说明

本仓库仅存放编译后的更新包与版本元数据。
